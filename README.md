# CivicPulse - Civic Redressal Hub

Full-stack platform for Nagpur Municipal Corporation.

## Tech Stack
- Node.js/Express backend
- MongoDB Atlas (Mongoose)
- Leaflet.js maps centred on Nagpur [21.1458, 79.0882]
- OpenStreetMap/Nominatim geocoding

## Setup
1. npm install
2. cp .env.example .env (fill in MONGODB_URI)
3. npm start
